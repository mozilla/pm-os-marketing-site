# PM OS Marketing Site

Marketing and documentation site for PM OS, deployed to [pm-os.quick.mozilla.cloud](https://pm-os.quick.mozilla.cloud/).

## Deployment

Automatically deployed to Quick via GitHub Actions on push to `main`. No manual deployment needed.

## Local Preview

```bash
open index.html
```

## Making Changes

1. Edit `index.html` directly
2. Commit and push to `main`
3. GitHub Actions auto-deploys to Quick (~30 seconds)

No branch protection - push directly to `main` for quick updates.
