Getting Started

Complete onboarding from zero to first skill. Takes 60-90 minutes total. Once you link GitHub to people.mozilla.org, you'll get an org invite automatically.

New to the PM OS? Point Claude at This Website

Paste this URL into Claude Code and say:

"I just installed the PM OS. Walk me through getting started based on this guide."

Claude will read this site and personalize onboarding to your role.

# Step 1: Link GitHub to Mozilla Identity

Mozilla matches your GitHub username to your work identity through people.mozilla.org.

  1. Go to people.mozilla.org and log in with Mozilla SSO
  2. Click your name → My Profile
  3. Scroll to Contact / Identities
  4. Click the pencil → Choose GitHub → Verify

# Step 2: Accept Your Mozilla GitHub Org Invitation

Mozilla staff: Once you link your GitHub account to people.mozilla.org (Step 1), you'll automatically receive an email from GitHub inviting you to the Mozilla org within 2 hours. Check both your work email and personal email — GitHub sends the invite to the email address associated with your GitHub account.

No invite after 2 hours? First, confirm your GitHub account is actually linked in your people.mozilla.org profile (Step 1). If it's linked correctly, contact IT for help.

Important: GitHub cancels invitations not accepted within 1 week.

Need membership in a specific team? File a Bugzilla ticket in the mozilla.org :: Github: Administration component requesting the team name (e.g., product-management).

# Step 3: Install Git and GitHub CLI

Tip: You can copy-paste this entire step into Claude Code and let it do most of this for you.

# Open a terminal

macOS: Press Cmd+Space, type "Terminal", press Enter. The built-in Terminal app works fine.

Windows: Press the Windows key, type "Windows Terminal", press Enter. (On Windows 11 this is pre-installed; on Windows 10 install it from the Microsoft Store.)

# Install git and the GitHub CLI

macOS:

Step 1: Install Homebrew (Mac's package manager). Paste this one line and press Enter:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

This asks for your Mac login password (the one you use to unlock your laptop). Nothing will appear as you type it — that's normal. Type, press Enter, wait.

If Homebrew prints two lines starting with eval and tells you to run them, do that.

Verify Homebrew is wired up:

brew --version

You should see something like Homebrew 4.x.x. If you get "command not found," close and reopen your terminal, then retry.

Step 2: Install git and gh in one line:

brew install git gh

This takes 1–5 minutes. When done, verify both:

git --version
gh --version

You should see git version 2.x.x and gh version 2.x.x.

Windows:

Step 1: Install Git for Windows. Download the installer from git-scm.com/download/win and run it with all defaults.

Step 2: Install the GitHub CLI. In PowerShell, paste this one line:

winget install --id GitHub.cli

If winget is not recognized, download the installer from cli.github.com instead.

Close and reopen Windows Terminal, then verify both:

git --version
gh --version

# Sign in to GitHub from the terminal

Paste this one line and press Enter:

gh auth login

gh will ask you a series of questions. Answer them with the arrow keys + Enter:

  1. What account do you want to log into? → GitHub.com
  2. What is your preferred protocol for Git operations? → HTTPS
  3. Authenticate Git with your GitHub credentials? → Yes
  4. How would you like to authenticate GitHub CLI? → Login with a web browser
  5. It prints a one-time code (e.g., ABCD-1234). Copy the code first, then press Enter.
  6. Your browser opens to GitHub. Paste the code, click Continue, click Authorize github.
  7. CRITICAL: Scroll down to "Single sign-on organizations". Find Mozilla and click Authorize next to it. Without this, you can't read Mozilla repos.
  8. Close the browser tab. You should see "✓ Authentication complete."

Then wire git to use gh's credentials:

gh auth setup-git

It prints nothing on success — that's normal. This prevents the "password required" prompt that everyone gets stuck on.

# Step 4: Set Up SSH Keys for Mozilla Repos

Why this matters: Mozilla's internal repos require SSH authentication with SSO authorization. Skipping this step causes the "Plugin not found" error in Step 5.

Generate the key (replace the email with your GitHub account email):

ssh-keygen -t ed25519 -C "your-github-account-email@example.com"

When it asks "Enter file in which to save the key," just press Enter. When it asks for a passphrase, press Enter twice to leave it empty.

Add the key to the ssh-agent:

macOS:

eval "$(ssh-agent -s)"
ssh-add --apple-use-keychain ~/.ssh/id_ed25519

The first line starts the agent. The second adds your key and saves it in macOS Keychain.

Windows (PowerShell):

Get-Service ssh-agent | Set-Service -StartupType Automatic
Start-Service ssh-agent
ssh-add $env:USERPROFILE\.ssh\id_ed25519

Windows (Git Bash):

eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519

Copy the public key to your clipboard:

macOS:

pbcopy < ~/.ssh/id_ed25519.pub

Windows (PowerShell):

Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub | Set-Clipboard

Windows (Git Bash):

clip < ~/.ssh/id_ed25519.pub

Add the key to GitHub:

  1. Go to github.com/settings/keys → New SSH key
  2. Title: My laptop
  3. Paste the key (Cmd+V / Ctrl+V) into the Key field
  4. Click Add SSH key
  5. CRITICAL: Find your new key in the list, click Configure SSO → Authorize next to Mozilla. Without this, the key works for personal repos but is rejected by Mozilla repos.

FAQ

Common questions and troubleshooting.

I get "Plugin 'pm-os-base' not found in marketplace"

This means Claude Code can't access the mozilla/internal-aidev-plugins repo. Most common cause: you haven't set up SSH keys yet.

Complete Step 4: Set Up SSH Keys for Mozilla Repos in Getting Started, especially the Configure SSO → Authorize step. Without SSO authorization on your SSH key, Claude Code can read the marketplace but can't clone the actual plugin repo.

After completing Step 4, retry /plugin install pm-os-base@internal-aidev-plugins.

I get "Repository not found" when installing the plugin

This means you don't have access to mozilla/internal-aidev-plugins yet. Check Step 1 in Getting Started — you should see "View as member" on github.com/mozilla. If you see "View as public," your Bugzilla ticket hasn't been approved yet.

Git asks for a password during install

You skipped gh auth setup-git in Step 3. Run it now.

Atlassian MCP is erroring

Run /pm-os-base:manage, select setup 2 (Atlassian). This runs the install script that fixes the known dependency issue.

BigQuery queries fail with "ADC expired"

Your Google Cloud credentials expired. Run:

gcloud auth application-default login

Slack/Zoom say "Requires Claude Code"

These integrations only work in Claude Code (not Cursor, VS Code, etc.) because they use Claude Code's built-in OAuth system. Mozilla's Slack workspace only approved the Anthropic Slack app.

A skill says "[Integration] not configured"

The skill tried to use an integration you haven't set up. Run /pm-os-base:manage to enable it. The skill should still work, just with reduced functionality.

How do I customize a skill's output?

See Overview → Tips section. Copy the skill to Personal/skills/, edit it, and your version overrides the default.

Is my personal data shared with anyone?

No. Everything in ~/pm-os/Personal/ is gitignored and never leaves your machine. The plugin itself is read-only and shared.

How do I update the PM OS when a new version comes out?

Enable auto-updates (recommended): The PM OS doesn't auto-update by default. Run this once to enable it:

/plugin

Navigate to the PM OS entry, select it, and toggle Auto-update on. This ensures you get new features, bug fixes, and integration improvements automatically.

Manual update: Run /plugin update pm-os-base@internal-aidev-plugins anytime to pull the latest version.
